# PartSelect Support Assistant

**Live Demo:**
https://your-vercel-url.vercel.app

## Overview

PartSelect customers often need help determining which replacement part they need, whether a part is compatible with their appliance model, and how to install it correctly.

This project is a domain-restricted commerce and support assistant focused on refrigerator and dishwasher parts.

The assistant combines deterministic product tools, compatibility validation, troubleshooting workflows, and lightweight live PartSelect grounding to provide reliable customer support while avoiding hallucinated product recommendations.

The goal is to deliver an experience that feels like a support assistant embedded directly into an e-commerce website rather than a generic chatbot.

---

## Key Features

### Product Lookup

Search for refrigerator and dishwasher replacement parts using:

* Part numbers
* Product names
* Appliance categories
* Symptoms

### Compatibility Verification

Verify whether a replacement part is compatible with a specific appliance model.

Compatibility decisions are made using structured product data rather than AI-generated reasoning.

### Installation Guidance

Provide step-by-step installation instructions for supported parts.

### Troubleshooting

Guide users through common appliance issues before recommending replacement parts.

Examples:

* Ice maker not working
* Dishwasher leaking
* Water supply issues

### Session Memory

The assistant remembers:

* Current appliance model
* Recently viewed part
* Troubleshooting context

This enables natural multi-turn conversations.

### Domain Restriction

The assistant only supports refrigerator and dishwasher parts.

Out-of-scope requests are intentionally rejected.

## Design Principles

### 1. Deterministic Product Facts

Compatibility, pricing, installation steps, and troubleshooting information are never generated by an AI model.

These facts originate from:

* Structured product data
* Verified PartSelect content
* Local catalog fallback data

### 2. Domain Restriction

The assistant intentionally operates within a narrow domain.

This improves reliability and reduces hallucination risk.

### 3. Extensibility

The current implementation uses local catalog data and lightweight live retrieval.

The same tool contracts can later connect to:

* Production catalog databases
* Vector search systems
* Crawlers
* Background ingestion pipelines

without changing the user experience.

## Validation

Part number validation lives in:

```text
lib/validation.ts
```

Supported format:

```text
PS + at least 6 digits
```

Examples:

```text
Valid:
PS11752778

Invalid:
PS112
PS
11752778
```

Incomplete part numbers trigger clarification requests rather than product lookups.

## Memory

Session memory is lightweight and browser-scoped.

Tracked context:

* currentModelNumber
* applianceType
* selectedPart
* troubleshootingContext
* cartItems

Example:

```text
User:
My model number is WDT780SAEM1.

User:
Is PS11752778 compatible with it?
```

The assistant can reuse stored context without asking for the model again.

## Live Website Grounding

The assistant can retrieve PartSelect content on demand.

Current retrieval flow:

```text
User Query
 ↓
PartSelect Discovery
 ↓
Page Fetch
 ↓
Content Extraction
 ↓
Tool Layer
 ↓
Response
```

Capabilities:

* Lightweight PartSelect lookup
* Product page retrieval
* Repair guide retrieval
* Structured extraction
* Local fallback catalog

The system does not crawl the full PartSelect catalog during chat requests.

Live retrieval is opportunistic and bounded by strict timeout limits.

## Tradeoffs

Given the scope of the case study, I prioritized:

* Reliable product recommendations
* Explainable behavior
* Structured compatibility validation
* Grounded responses
* User experience

over:

* Full catalog crawling
* Production-scale infrastructure
* Authentication
* Checkout flows
* Large-scale vector search

The result is a focused vertical slice that demonstrates how an AI-powered commerce assistant could evolve into a production-ready PartSelect support experience.
